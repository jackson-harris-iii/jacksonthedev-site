# A short list, in the order you need it

Use these for a project. Don't make watching everything the assignment.

1. **[Stop Prompting Claude. Use Karpathy's Method Instead. — Austin Marchese](https://www.youtube.com/watch?v=7zZy1QTvokM)** (~13 minutes). The core explainer: spec from 1:11, verification from 6:04, reusable environment from 8:48. Pause after each section and apply it. Review basis: full auto-caption transcript, not frame-by-frame visual review. The title and three-layer synthesis belong to the presenter; speed claims and every underlying attribution have not been independently established.
2. **[7 Codex Skills I Use on Every Project (2026) — James NoCode](https://www.youtube.com/watch?v=E8T_Fa6ZFKw)** (~28 minutes). Optional demonstration for lesson 3. Begin with 0:34–3:00 on packaging repeated instructions. The introductory excerpt was reviewed; later tool-specific demonstrations are supplementary, not prerequisites.
3. **[Building a Software Factory that actually works (Full Course) — Greg Isenberg](https://www.youtube.com/watch?v=_LCeJZFIsd4)** (~31 minutes). Developer extension after the core exercises. Discuss isolated implementation, evidence, review, and a human release decision. Reviewed caption source available in Jackson's research notes. Don't start a non-coder here.
4. **[LLM Wiki — Andrej Karpathy](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)**. A primary-source idea for preserving sources, maintaining a linked synthesis, and recording changes. Read when you have repeated questions that need a durable knowledge base. A folder is not model training, and a generated summary is not its source.
5. **[Building effective agents — Anthropic](https://www.anthropic.com/engineering/building-effective-agents)**. Optional engineering reading for deciding when a simple workflow is enough and where tools and feedback help. Read before increasing autonomy.
6. **[Retrieval practice — The Learning Scientists](https://www.learningscientists.org/retrieval-practice)** and **[six learning strategies](https://www.learningscientists.org/blog/2016/8/18-1)**. Background for recall questions and later rechecks. We adapt to preferences and accessibility needs, not fixed “learning style” labels.

The first three videos were found in Jackson's YouTube watch history during the September 30 review. History is evidence of exposure, not mastery. No full videos, transcripts, Twitter posts, or course materials are redistributed here. Additional social posts enter a review queue only after their actual content and source have been inspected.

## Corrections to keep in mind

- A second model can suggest problems; agreement does not establish correctness. Test calculations, inspect actual results, and reconcile against reliable sources.
- A deployment receipt establishes a deployment event. It does not prove the deployed application works correctly.
- Workspace instructions guide behavior. Enforced permissions require correctly configured controls; a single hook is not a universal guarantee against every path to a resource.
- Access through your browser does not automatically authorize a third-party AI tool to process an employer's information.
- A personal knowledge folder provides context. Calling it “training data” can misleadingly imply it retrains the model.
